# Digital Innovation - Site Web d'Agence Digitale

Site web responsive pour Digital Innovation, une agence web basée au Bénin spécialisée dans la transformation digitale.

## 🚀 Comment lancer le site

### Dans Replit
1. Ouvrez le fichier `digital-innovation-agency/index.html`
2. Cliquez sur le bouton "Preview" ou "Webview" dans Replit
3. Le site s'affichera dans le navigateur intégré

### En local
1. Ouvrez simplement le fichier `index.html` dans votre navigateur web
2. Aucune installation ou serveur n'est nécessaire

## 🎨 Personnalisation

### Modifier les couleurs

Les couleurs sont définies comme variables CSS dans `styles.css`. Modifiez les valeurs dans la section `:root` :

```css
:root {
  --bg-dark: #070707;        /* Fond noir profond */
  --accent-green: #00e06a;   /* Vert néon (couleur principale) */
  --muted-blue: #d8eef7;     /* Bleu clair (section "Qui sommes-nous") */
  --deep-blue: #04106a;      /* Bleu foncé (footer) */
  --card-dark: #0c0d0e;      /* Fond des cartes */
  --text-light: #e6f0f5;     /* Texte clair */
  --text-dark: #0b2030;      /* Texte foncé */
}
```

### Modifier les textes

Tous les textes sont en français et peuvent être modifiés directement dans `index.html`. Les sections principales :

- **Hero** : Titre principal et sous-titre
- **Qui sommes-nous** : Description de l'agence et services
- **Workflow** : Les 6 étapes du processus
- **Blog** : Articles et descriptions
- **Footer** : Coordonnées et informations de contact

### Modifier les polices

Les polices utilisées sont :
- **Poppins** (300, 400, 600, 700) - Corps de texte
- **Space Grotesk** (700) - Titres

Pour changer les polices, modifiez les imports Google Fonts dans `index.html` et les variables dans `styles.css`.
